# Security

The agent sends texts, calls and messages, so safety matters. If you find a way to make it send without consent, ignore an opt-out, skip a required notice, accept an unsigned request, or leak a secret, please email **support@eyeguide.ai** with the details instead of opening a public issue. We will reply within a few days and credit you if you like.

Please do not include real phone numbers, tokens or customer data in reports.
